# Study Planner

A full-stack study tracking web app built with FastAPI, SQLAlchemy and SQLite.

## Features
- Add and manage study subjects with daily goals
- Log study sessions with duration and notes
- Dashboard with progress bars, streaks and goal tracking
- Weekly bar chart of minutes studied per day
- Session history with filters and delete

## Tech Stack
Python · FastAPI · SQLAlchemy · SQLite · Pydantic · JavaScript

## Run Locally
pip install fastapi uvicorn sqlalchemy pydantic
uvicorn main:app --reload

Visit http://localhost:8000/docs
